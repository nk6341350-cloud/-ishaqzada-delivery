# اسحاق‌زاده ډیلیوري — خپلواک نسخه

دا پروژه د ChatGPT ننوتلو یا ChatGPT Sites ته اړتیا نه لري. د موبایل/PIN حسابونه، درې رولونه، آرډرونه، راپورونه او عکسونه د اصلي اپلیکیشن له کوډ څخه ساتل شوي. د چلولو لپاره ستاسو خپل Cloudflare حساب، Workers، D1 ډیټابېس او R2 bucket ته اړتیا ده. یوازې GitHub د چلولو سرور او ډیټابېس نه دی.

## خپرول

1. د ZIP ټول فایلونه وباسئ او په خپل **شخصي GitHub** کې Private repository ته یې واچوئ. `index.html` په `public/` کې دی، خو ټول فولډر اړین دی. PIN، setup code او د معلوماتو backup په GitHub کې مه ساتئ.
2. په خپل Cloudflare حساب کې د Node.js له ترمینل څخه `npm install` او `npx wrangler login` وچلوئ.
3. `npx wrangler d1 create ishaqzada-delivery-db` وچلوئ. د ترلاسه شوي database ID ارزښت په `wrangler.jsonc` کې د `REPLACE_WITH_YOUR_D1_DATABASE_ID` پر ځای ولیکئ.
4. `npx wrangler r2 bucket create ishaqzada-delivery-photos` وچلوئ. د R2 کارولو لپاره کېدای شي ستاسو د Cloudflare حساب د billing فعالولو شرط وي؛ مخکې یې په خپل حساب کې وګورئ.
5. `npm run migrate` وچلوئ. دا د نوي ډیټابېس جدولونه جوړوي.
6. دوه **بېلابېل، اوږده، پټ** ارزښتونه په خپل حساب کې وساتئ: `npx wrangler secret put SETUP_CODE` او `npx wrangler secret put PIN_PEPPER`. کوډونه په فایلونو کې مه لیکئ. د `PIN_PEPPER` له ورکېدو سره د پخوانیو PIN حسابونو ننوتل نه کېږي.
7. `npm run deploy` وچلوئ. خپل نوی `workers.dev` لینک پرانیزئ، د `SETUP_CODE` په وسیله اډمین جوړ کړئ، وروسته شاګردان ثبت او تایید کړئ.

## د پخواني ژوندۍ نسخې معلومات

په دې بسته کې د اوسني سایټ **ژوندۍ ډیټابېس او اپلوډ شوي عکسونه نشته**. نو په نوي لینک کې به حسابونه او آرډرونه په خپله نه راڅرګندېږي. د پخوانیو معلوماتو د انتقال لپاره باید د اوسني کوربه له D1 څخه database export، د R2 څخه عکسونه، او هماغه `PIN_PEPPER` په خوندي ډول انتقال شي. که د پخواني کوربه حساب ته لاسرسی ونه لرئ، هغه معلومات له HTML یا GitHub څخه بېرته نه شي اخیستل کېدای. د نویو حسابونو جوړولو لپاره پخوانی رمز لازم نه دی.

دا خپرونه د ChatGPT ایمیل پورې تړلې نه ده؛ د Cloudflare حساب، د نوموړي شرکت د خدمتونو دوام او د هغه د استعمال حدونه بیا هم اړین دي. د تل لپاره بې لګښته او بې انقطاع کار تضمین نه شي کېدای. د سایټ له کارولو سره سم منظم backup واخلئ.
